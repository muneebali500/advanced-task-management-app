    Vivid Tasks

    Modern Task Management — Focus on what matters

    📖 What It Does

    Vivid Tasks is a feature-rich personal task manager that helps you organize, prioritize, and track everything on your plate. With category filtering, time tracking, drag-and-drop reordering, and smart stats — staying productive has never looked better.

    🎮 How to Use

    • Click New Task (or press N) to create a task
    • Set a due date, priority level, and category for each task
    • Use the sidebar or filter chips to view tasks by status or category
    • Click any task to open the detail panel with time tracking
    • Drag and drop tasks to reorder them manually
    • Use the sort dropdown to order by due date, priority, or name
    • Press Esc to close any open panel

    ✨ Key Features

    • Time Tracking: Built-in timer per task to log time spent
    • Smart Filters: Today, Upcoming, Overdue, High Priority & more
    • Categories: Work, Personal, Health, Learning
    • Drag & Drop: Reorder tasks with manual sorting
    • Live Stats: Completion rate, overdue count, today's tasks
    • Responsive: Works seamlessly on mobile and desktop
    • Persistent: Tasks saved locally — no account needed

    🚀 Key JavaScript Concepts

    • Class-based Architecture: Full OOP approach with a single VividTasks class managing all state
    • localStorage: Persistent data storage — tasks survive page refreshes
    • Drag & Drop API: Native HTML5 dragstart, dragover, and drop events for reordering
    • setInterval / clearInterval: Precise per-task time tracking with live display updates
    • DOM Manipulation: Dynamic task rendering via innerHTML and event delegation
    • Event Handling: Keyboard shortcuts, filter chips, form submissions, and inline handlers
    • Array Methods: filter(), find(), findIndex(), map(), sort() for task management
    • ES6+ Features: Arrow functions, template literals, destructuring, spread operator

    🎨 Design Features

    • Dual-font system — Poppins for body text, Space Grotesk for headings
    • CSS custom properties (variables) for consistent theming throughout
    • Smooth micro-interactions — hover lifts, active states, and slide-in animations
    • Responsive grid layout adapting from 3-column desktop to single-column mobile
    • Priority-coded color system: red for high, amber for medium, green for low
    • Slide-down task creator with animated entrance and graceful exit
    • Toast notification system with type-based color coding and auto-dismiss
    • Accessible focus states, high-contrast mode support, and reduced-motion respect
